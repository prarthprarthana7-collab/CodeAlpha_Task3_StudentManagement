# CodeAlpha Task 3 - Student Management System

## About the Project

This project is developed as part of the CodeAlpha C Programming Internship.

The Student Management System is a menu-driven C program that manages student records using structures and file handling.

## Operations Performed

- Add Student
- Delete Student
- Update Student
- Search Student
- Display Students
- Exit

## Technologies Used

- C Programming
- Structures
- File Handling
- Functions

## How to Run

Compile:

gcc student.c -o student

Run:

./student

## Student Details

The program stores:

- Roll Number
- Name
- Marks
